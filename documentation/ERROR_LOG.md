# Sectorscanner – Fehlerprotokoll

**Status:** Aktiv.  
**Zentrale Regelquelle:** `workflow/DOCUMENTATION_STANDARD.md`

Aktuell sind in Sectorscanner keine bestätigten eigenständigen Fehler unter einer FEHLER-ID registriert.

Neue bestätigte Fehler werden dauerhaft mit stabilem `FEHLER-###`-Bezeichner und ausschließlich dem Archivstatus `[offen]` oder `[erledigt]` dokumentiert. Für tatsächlich behobene Fehler wird bei Bedarf eine Maßnahmenhistorie als eigene Projektquelle angelegt und der Bootstrap im selben freigegebenen Zusammenhang aktualisiert.
